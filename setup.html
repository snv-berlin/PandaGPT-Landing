Setup Guide

PandaGPT is currently running on non-public infrastructure that can only be accessed through a VPN connection. Follow these steps to connect to PandaGPT

Privacy Notice: This VPN uses a split-tunnel configuration. Only traffic to pandagpt.org is routed through the VPN tunnel. All other internet traffic remains on your regular connection and is not affected.

1

Download OpenVPN Client

First, you need to install the OpenVPN Connect client on your device.

For Windows & macOS

Download OpenVPN Connect

For Linux

sudo apt-get install openvpn

Or use your distribution's package manager

2

Install Your VPN Profiles

You should have received two OpenVPN configuration files (.ovpn) via email: one for UDP and one for TCP.

Check Your Email

Look for an email with the subject containing "PandaGPT Access"

Import Both Profiles

  • •Open OpenVPN Connect
  • •Click on "Import Profile" or drag and drop the first .ovpn file (UDP)
  • •Rename the profile to panda-internal-test-udp
  • •Repeat the process with the second .ovpn file (TCP)
  • •Rename the profile to panda-internal-test-tcp
3

Connect to VPN

Connect to the VPN to access PandaGPT.

  • •Open OpenVPN Connect
  • •Find your imported panda-internal-test-udp profile
  • •Click the toggle/connect button
  • •Wait for the connection to establish (status should show "Connected")
  • •If connection fails, try the panda-internal-test-tcp profile instead
4

Access PandaGPT

Once connected, you can access the PandaGPT application.

Open your web browser and navigate to: https://test.pandagpt.org

Troubleshooting

VPN won't connect?

Make sure you have an active internet connection and that no firewall is blocking OpenVPN. Try switching between UDP and TCP profiles – some networks (especially corporate or public WiFi) work better with TCP.

Can't access test.pandagpt.org?

Verify that your VPN connection is active (check OpenVPN Connect status). Try refreshing the page or clearing your browser cache. If the domain still doesn't work, try accessing the application directly via IP address: 10.0.2.188 or 10.0.2.227
