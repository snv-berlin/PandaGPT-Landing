Setup Guide

PandaGPT is currently running on non-public infrastructure that can only be accessed through a VPN connection. Follow these steps to connect to PandaGPT

Privacy Notice: This VPN uses a split-tunnel configuration. Only traffic to pandagpt.org is routed through the VPN. All other traffic uses your regular connection.

1

Download OpenVPN Client

Install the OpenVPN Connect client on your device.

Windows & macOS

Download OpenVPN Connect

Linux

sudo apt-get install openvpn

Or use your distribution's package manager

2

Install Your VPN Profiles

You should have received two OpenVPN configuration files (.ovpn) via email with the subject "PandaGPT Access". Install both profiles and rename them as follows:

  1. 1.Open OpenVPN Connect
  2. 2.Double-click the first .ovpn file or drag it into the OpenVPN window, then confirm the import
  3. 3.Click the menu button in the top left, navigate to "My Profiles", and rename this profile to panda-internal-test-udp
  4. 4.Repeat steps 2–3 with the second .ovpn file and rename it to panda-internal-test-tcp

UDP is faster and works on most networks. TCP is more reliable and may work better on restrictive networks (corporate or public WiFi) where UDP is blocked.

3

Connect to VPN

Open OpenVPN Connect, find your panda-internal-test-udp profile, and click the toggle button to connect. Wait for the status to show "Connected". If the connection fails, try the panda-internal-test-tcp profile instead.

4

Access PandaGPT

Once connected, you can access the PandaGPT application.

Open your web browser and navigate to: https://test.pandagpt.org

Troubleshooting

VPN won't connect? Make sure you have an active internet connection and no firewall is blocking OpenVPN. Try switching between UDP and TCP profiles – some networks work better with TCP.

Can't access test.pandagpt.org? Verify your VPN is active in OpenVPN Connect. Try refreshing the page or clearing your browser cache. If the domain doesn't work, try the IP addresses: 10.0.2.188 or 10.0.2.227
