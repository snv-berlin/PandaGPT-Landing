Setup Guide

PandaGPT is currently running on non-public infrastructure that can only be accessed through a VPN connection. Follow these steps to connect to PandaGPT

Privacy Notice: This VPN uses a split-tunnel configuration. Only traffic to subdomains of pandagpt.org is routed through the VPN. All other traffic uses your regular connection.

1

Download AWS Client VPN

Install the AWS Client VPN client on your device.

Download AWS Client VPN

Select the appropriate version for your operating system (Windows, macOS, or Linux)

2

Import and Name Your VPN Profiles

You should have received two OpenVPN configuration files (.ovpn) via email with the subject "PandaGPT Prototype Access": panda-internal-test-udp.ovpn and panda-internal-test-tcp.ovpn

  1. 1. Save both profile files from the email to your computer
  2. 2. Open AWS Client VPN and go to File → Manage Profiles → Add Profiles. This will open a popup window
  3. 3. In the popup, click "Select File" and choose the first file panda-internal-test-udp.ovpn. Enter the Display Name: panda-internal-test-udp and click "Add"
  4. 4. Repeat steps 2-3 for the second file panda-internal-test-tcp.ovpn, using Display Name: panda-internal-test-tcp

UDP is faster and works on most networks. TCP is more reliable and may work better on restrictive networks (corporate or public WiFi) where UDP is blocked.

3

Connect to VPN

In AWS Client VPN, find your panda-internal-test-udp profile, and click the "Connect" button. Wait for the status to show "Connected". If the connection fails, try the panda-internal-test-tcp profile instead.

4

Access PandaGPT

Once connected, wait approximately 3 minutes for routing and DNS settings to finish setting up before accessing the PandaGPT application.

Note: This waiting period is only necessary after first connecting to the VPN. Subsequent connections do not require waiting.

Wait timer: 03:00

After waiting, open your web browser and navigate to: https://test.pandagpt.org

Troubleshooting

VPN won't connect? Make sure you have an active internet connection and no firewall is blocking AWS Client VPN. Try switching between UDP and TCP profiles – some networks work better with TCP.

Can't access test.pandagpt.org? Verify your VPN is active in AWS Client VPN. Try refreshing the page, clearing your browser cache, or switching to a different browser.

Expert: DNS Configuration

When connected to the split tunnel, the test.pandagpt.org domain should be resolved using a DNS server inside the subnet where the VPN connects. The DNS server IP is 10.0.0.2 and it resolves the domain to an IP address in the 10.0.0.0/16 subnet. Multiple IPs in that subnet are valid results.

When troubleshooting DNS issues, first verify that a route to the 10.0.0.0/16 subnet exists over the VPN Client. Then check if test.pandagpt.org can be resolved using DNS server 10.0.0.2 to an IP address in the 10.0.0.0/16 subnet.

DNS works but browser won't load? If DNS resolution works correctly but your browser still won't load the site, try flushing your OS DNS cache, clearing your browser cache, switching to a different browser, or using an incognito/private browsing window.

Still not working? If none of the cache clearing or flushing works, and you have verified that DNS resolution works correctly, try visiting or .

Note: Only visit these alternative domains after verifying DNS resolution works to prevent DNS cache poisoning.
